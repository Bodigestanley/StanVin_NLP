# ReturnIQ 15-phase implementation checklist

| Phase | Work | Source status |
|---|---|---|
| 1 | Define problem and four target labels | Implemented |
| 2 | Research data sources and verify licence/provenance | Guidance included; owner must verify chosen source |
| 3 | Clean, deduplicate and annotate data | Preprocessing validation included; human annotation required |
| 4 | EDA and class-balance inspection | Dataset summary endpoint/UI; deeper EDA still needed |
| 5 | Stratified train/test split and leakage checks | Stratified split scripts; source-level leakage review required |
| 6 | TF-IDF + Logistic Regression baseline | Implemented |
| 7 | Fine-tune DistilBERT locally | Training script implemented; run on verified dataset |
| 8 | Accuracy, precision, recall, F1 and confusion matrix | Metrics generated by training scripts |
| 9 | Error analysis and model comparison | TF-IDF error export; inspect and document errors |
| 10 | FastAPI single and batch inference | Implemented |
| 11 | PostgreSQL schema and prediction persistence | SQLAlchemy persistence and schema included; verify locally |
| 12 | React dashboard, prediction, batch, dataset and model pages | Implemented local UI/API integration |
| 13 | Frontend/backend integration and API tests | Basic tests included; run locally |
| 14 | Architecture and reproducible documentation | Included |
| 15 | Final validation and demo hardening | Must be completed on the actual machine and verified dataset |

**Important:** This is a source implementation, not evidence that all external prerequisites have been satisfied. Model artifacts, real dataset validation, local database credentials, and final performance results are environment-dependent.
